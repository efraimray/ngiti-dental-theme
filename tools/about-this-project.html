What this is

Ngiti Dental is a classic WordPress theme for dental clinics and other professional practices in the Philippines, built by Efraim Ray. The pages you are clicking through are a static export of the real theme running on WordPress 6.5, with the server features simulated in the browser.

The problem it solves

Most small clinics in Bukidnon and Mindanao take bookings through Messenger and phone calls, and their websites (if any) are a single page with outdated hours. Patients cannot see prices, cannot tell if the clinic is open right now, and have no clear way to request a slot. This theme gives a clinic a complete, fast, bilingual-ready website that the staff can edit in WordPress without a page builder.

Features

  • Nine page templates: Home, About, Services & Fees, Our Dentists, Appointment Request, Patient FAQ, Contact, Privacy Notice (RA 10173) and Disclaimer, plus a 404 page.
  • Services and Team as custom post types with duration, starting price (₱), icon, tooth groups, role, credentials and initials avatars.
  • Appointment request and contact forms handled by the theme: nonce, honeypot, rate limit, sanitizing, PH mobile validation, closed-day checks, a saved private "Request" post, an email via wp_mail() and a reference number.
  • Clinic details and opening hours in the Customizer, used everywhere: header, footer, sticky call/Messenger buttons, hours table, live "Open now" badge and Dentist JSON-LD.
  • Tooth finder on the FDI chart that dentists use: tap a tooth to see its name and the services that usually apply.
  • Light and dark mode, skip link, visible focus, labelled forms, responsive down to 360 px, self-hosted fonts and zero external requests.
  • One-click sample content: pages with templates assigned, services, team members and both menus.

Tech stack and languages

  • PHP (WordPress theme API, Customizer API, custom post types, admin-post form handler).
  • CSS with custom properties for the design system and both colour themes.
  • Vanilla JavaScript for the menu, theme toggle, open-now badge, form validation and tooth finder.
  • JSON for the shared sample content; Python for the arch illustration and the static export.

Install

  1. Download ngiti-dental-theme.zip from the GitHub release.
  2. In wp-admin go to Appearance → Themes → Add New → Upload Theme, choose the zip and activate it.
  3. Click Create sample content in the notice, then edit Appearance → Customize → Clinic details.

For clients

This is a ready starting point for a dentist, veterinary clinic, physical therapy clinic or law office website. Rebranding takes a day: name, colours, logo, services, team photos, prices and hours. Efraim Ray sets it up, connects the forms to email or Google Sheets, and hands over a site the staff can update themselves.
